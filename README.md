# Dental Clinic Website

A responsive front-end website for a dental healthcare clinic, featuring detailed service descriptions, appointment requests, and doctor profiles.

🔗 **Live Site:** https://ummehani2006.github.io/dentest/

## ✨ Features
- Service descriptions for dental treatments
- Doctor profile listings
- Appointment request section
- Fully responsive across desktop and mobile
